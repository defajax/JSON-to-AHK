# JSON to AutoHotkey

A small portfolio project built with JavaScript, React, and Vite. The web page converts a JSON array of keypresses into an AutoHotkey v2 script. The JSON is processed locally in the browser and is never sent to a server.

## Key Mapping Customization

In the "Key Mappings" section, you can customize the letters or AutoHotkey key names for Key0–Key14. The initial values match the original Python script. Modified values are saved in your browser's localStorage; clicking "Reset to Defaults" will restore the default key layout.
